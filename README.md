# PowerShell Scripts

Repozytorium zawiera praktyczne skrypty PowerShell wspierające codzienną administrację środowiskiem Windows Server i Active Directory. Skrypty mają charakter laboratoryjny oraz portfolio — pokazują automatyzację typowych zadań administratora IT.

## Zakres

- zarządzanie użytkownikami i grupami Active Directory
- backup informacji o członkostwie użytkownika w grupach
- pobieranie podstawowych informacji o serwerach
- tworzenie udziałów użytkowników
- migracja udziałów sieciowych
- Wake-on-LAN
- proste narzędzia wspierające zadania operacyjne

## Cel repozytorium

Celem repozytorium jest pokazanie praktycznego wykorzystania PowerShell do automatyzacji zadań administracyjnych. Skrypty porządkują powtarzalne czynności, ograniczają pracę manualną i mogą być rozwijane w kierunku bardziej kompletnych narzędzi administracyjnych.

## Dla kogo

Repozytorium jest przeznaczone dla administratorów Windows Server, osób uczących się PowerShell oraz kandydatów budujących portfolio w obszarze administracji infrastrukturą Microsoft.

## Technologie

PowerShell, Windows Server, Active Directory, udziały sieciowe, administracja systemowa, automatyzacja IT.
